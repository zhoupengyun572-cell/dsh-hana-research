# Hana Research（DSH 版）产品功能设计

- 状态：设计稿 v1（2026-08-15），待用户确认优先级后作为开发路线图
- 基础：OpenHanako 版 v0.15.0 功能集（已冻结归档）+ DSH 移植方案 `docs/PORT_PLAN.md`
- 视角：产品经理（用户价值） / 研究人员（学术工作流） / 工程（可实现性与风险）

## 1. 用户画像与核心工作流

**用户**：心理学研究者（情绪调节、青少年发展、临床与测量方向，从 seed 数据与期刊选题推断），日常产出包括文献综述、实证研究、量表/工具开发。

**三条核心工作流**（产品定义，所有功能围绕它们组织）：

| 工作流 | 场景 | 现有支撑 | 本设计要补齐的 |
|---|---|---|---|
| A. 持续追踪 | 每天/每周扫一遍核心期刊近三期，不错过领域新进展 | 25 源同步 + 近三期保留 + 期刊更新栏 | 新文献徽标、AI 期刊简报、自定义期刊源 |
| B. 主题调研 | 围绕研究问题全网检索、去重、筛选、收藏、形成文献池 | 四源检索 + AI 解读 + 收藏 + 检索保存 | 文献集合、检索历史、阅读状态、优先级星标、引用导出 |
| C. 项目深读 | 把文献导入项目，PDF 精读、做证据笔记、沉淀为项目知识 | 导入/上传 + 阅读器 + 标签摘录 + 项目笔记 | 目录/书签、批注颜色体系、证据矩阵、AI 综述草稿、项目状态 |

## 2. 文献中心（文献检索与搜集）

### 2.1 继承功能（迁移不重写）

- 四源全网检索（OpenAlex / Crossref / arXiv / PubMed）+ AI 解读（复用宿主模型）
- 25 个心理学期刊源定时同步（20 国外 + 5 国内），近三期保留 + 在线优先封顶 + 超期清理
- 收藏 / 主题分类筛选 / 自定义标签（关键词级筛选）
- 检索 → 保存 → 收藏 → 导入项目闭环；PDF 合法下载（Unpaywall + 官网直连）
- Agent 工具与对话卡片

### 2.2 增强功能（按视角来源标注）

#### 产品经理视角（使用价值）

| # | 功能 | 说明 | 优先级 |
|---|---|---|---|
| L1 | **新文献徽标** | 期刊栏/文献列表标记"自上次查看以来新增"（`last_viewed_at`），支持一键"全部已读" | P1 |
| L2 | **自定义期刊源** | 用户按 ISSN/名称添加期刊（OpenAlex 收录即同步），与内置 25 源并列管理、可禁用 | P1 |
| L3 | **期刊分组视图** | 期刊按「国外 / 国内」「领域方向」分组折叠，支持只看关注的组 | P2 |
| L4 | **文献集合（Collections）** | 命名收藏集（"写综述用的""方法学参考"），文献可同时属于多个集合；集合可导出 | P1 |
| L5 | **阅读状态与优先级** | 每篇文献：未读/已读/正在读 + 进度；P0/P1/P2 星标；按状态筛选 | P1 |
| L6 | **检索历史与保存的检索** | 自动记录最近检索词；可命名保存（含来源/过滤条件），一键重跑；保存的检索可设"新结果提醒" | P2 |
| L7 | **AI 期刊简报** | 每周一键生成"你关注的 N 个期刊新增 X 篇，值得关注：…"（复用宿主模型，低 token 成本） | P2 |

#### 研究人员视角（学术价值）

| # | 功能 | 说明 | 优先级 |
|---|---|---|---|
| L8 | **引用导出** | 选中文献一键导出 BibTeX / RIS / 复制 APA 7 引用（含 DOI 与期刊缩写） | P1 |
| L9 | **被引次数与趋势** | 检索结果与文献卡显示 OpenAlex `cited_by_count`；可选"近 3 年被引"排序 | P1 |
| L10 | **方法学标注** | 给文献打"研究设计"标签（实验/相关/纵向/元分析）、测量工具、样本人群——与笔记标签统一体系 | P2 |
| L11 | **相似文献推荐** | 基于标题/主题词的相似文献建议（OpenAlex `related_works` 或本地关键词匹配） | P2 |
| L12 | **引文网络浏览** | 从一篇文献展开"参考文献 / 被谁引用"，构建主题脉络图（文本列表起步） | P2 |
| L13 | **中文来源补充** | 已直连心理学报官网下载；保持"合法接口"边界，不抓取知网；增加人工录入条目（无 DOI 也可入库） | P2 |

#### 工程视角（数据模型与实现）

- **标签体系升级（核心工程改动）**：当前笔记标签内嵌 `tags_json`、文献筛选标签存 localStorage——升级为 `tags`（id/名称/颜色/内置或自定义）+ `paper_tags` / `note_tags` 关联表（schema v5），统一文献标签、笔记标签、筛选标签，支持改名/合并/颜色/删除（L14，P1）
- **新增表**：`collections` + `collection_papers`（L4）、`reading_progress`（L5）、`saved_searches`（L6）、`custom_journals`（L2）
- 检索结果去重与缓存沿用现有实现；被引次数字段在保存时落库（不依赖实时 API）

## 3. 项目库

### 3.1 继承功能

- 项目 CRUD、文献导入（一键下载 / 本地上传）、同内容 PDF 去重
- PDF 阅读器（连续滚动、双栏几何选择、缩略图、全文搜索、快捷键）
- 标签化摘录（5 预设 + 自定义）、批注（高亮/框选）
- 项目级笔记（右侧面板、按文章分组、自动生成 Markdown、导出）
- AI 全文翻译（复用宿主模型）

### 3.2 增强功能

#### 产品经理视角

| P2 | **项目概览** | 项目抽屉顶部：文献数/已读进度/笔记数/最近活动时间；可生成项目摘要（AI，可选） | P1 |
| P3 | **文献角色标记** | 项目内每篇文献标记角色：核心文献/背景/方法参考/结果对比，按角色筛选 | P2 |

#### 研究人员视角

## 5. 优先级路线图

### P0 —— DSH 版 v1.0（功能等价迁移，先行交付）
文献中心四源检索 + AI 解读、25 期刊同步近三期、收藏/筛选/自定义标签、PDF 下载导入；项目库 CRUD/导入/阅读器/笔记/Markdown；16 工具 + 权限审计 + 对话卡片；AI 翻译（宿主模型）。

### P1 —— v1.1（高价值、低成本，随迁移顺路完成）
L1 新文献徽标 · L2 自定义期刊源 · L4 文献集合 · L5 阅读状态与优先级 · L8/BibTeX 导出（含 P7）· L14 标签管理 UI（颜色/改名/合并）· P1 项目状态类型 · P2 项目概览 · P9 目录书签 · P10 批注颜色 · P12 阅读进度续读 · A3 订阅主动汇报。

### P2 —— v1.2（研究与协作增强）
L6 保存检索与提醒 · L7/L9 被引次数与 AI 简报 · L10 方法学标注 · L11/L12 相似文献与引文网络 · P3 文献角色 · P4 证据矩阵 · P5 文献关系 · P6 AI 综述草稿 · P8 Word/PDF 导出 · P11 跨文献笔记。

### P3 —— 远期
L13 中文来源补充（人工录入先行）· P13 OCR · A4 一键流程。

## 6. 边界与风险

- **合法下载边界**：维持"检索可及 ≠ 可下载"分离；订阅制文献仅元数据；不抓取知网等受限站点
- **数据模型迁移**：标签体系升级（tags 表）涉及 schema v5，P1 阶段一次性迁移，迁移脚本保留旧数据
- **本地优先**：全部数据（库/PDF/笔记/配置）留在 `$DSH_HOME/plugin-data/hana-research/`，无云端
- **AI 成本控制**：AI 功能（翻译/解读/简报/综述）全部走宿主模型配置；简报/综述为显式触发，不默认烧 token
- **性能**：期刊同步沿用 24h 定时 + 串行节流；自定义源数量限制（≤20 个）防 429
