# UI 精修：学术文献档案馆 · 编辑排版风（2026-08-16）

按用户要求调用 `frontend-design` skill 选定设计方向后实施。**纯 CSS 追加精修层**（`assets/research.css` 末尾 Editorial Archive polish 区块），未改动任何功能规则与 JS 结构，全部颜色继续走宿主主题 token（12 套主题浅/深色自适应不变）。

## 设计方向

**「学术文献档案馆 / 学术年鉴」编辑排版风**——把研究工作台从「Zotero 式工具感」升级为「翻阅文献索引卡系统」的体验，记忆点：

- 衬线卷号序号：文献卡序号从等宽小字升级为 **Noto Serif SC 斜体 19px 卷号**（01/02…），hover 时朱砂点亮
- 装订线：文献卡左侧 2px 竖线（索引卡边缘条），hover 加粗伸长；项目卡/抽屉同理
- 刊眉式章节头：页面页眉与「开放获取文献」章节头升级为**双线刊眉 + § 前缀**；页眉标题衬线 25px，日期戳改为卷期样式（左侧朱砂竖条）
- 纸纹质感背景：body 固定层叠加**极淡网格线 + 双角 accent 晕染**（纯 CSS 渐变，零图片）
- 统一胶囊徽章体系：OA/状态/优先级/被引/方法学/角色/关系/译文徽章统一为 18px 胶囊 + 状态圆点，不再高低不齐
- 印刷按钮质感：主按钮加 accent 光晕；chip 胶囊化 + 选中朱砂点；期刊源 chip hover 微浮起
- 弹层编辑部化：modal 顶部 accent 渐变装饰线、kicker 圆点前缀、标题衬线化、圆角 12px
- 项目抽屉书脊：左侧 4px accent 渐变书脊条
- 入场 stagger：文献卡前 20 张按 22ms 阶梯浮现（reveal-card），不散点堆砌
- 证据矩阵排版表：表头衬线字距刊眉、斑马纹 + 行 hover
