# v34 PRISMA 流程与审计台账里程碑

日期：2026-08-27

## 本轮目标

在现有题录筛选、全文筛选和双人独立筛选基础上，补齐 PRISMA 2020 所需的来源级检索批次、去重前后数量、全文获取状态、排除原因汇总及可复核导出。

## 统计原则

- 当前项目只保存导入后的唯一文献，不能可靠反推检索前总量。
- 识别、去重和筛选前移除数量来自人工登记的检索批次，不用当前项目文献数伪造。
- 题录筛选、全文评估、排除理由和最终纳入来自实际筛选结论。
- 全文获取状态独立于“本地是否已有 PDF”；支持自动判断、获取中、已获取、无法获取及原因记录。
- 登记批次与当前项目数量不一致时显示口径警告，不隐藏差异。

## 已完成

- 数据库 schema 17 → 18，新增 `project_prisma_batches`，并为项目文献增加全文获取状态、原因和更新时间。
- 支持数据库、注册平台和其他来源三类检索批次；记录检索日期、检索式、发现数、去重数、其他移除数、导入项目数和备注。
- 校验数量关系，阻止负数、去重超过发现数、导入数超过移除后记录数等不可能数据。
- PRISMA 汇总覆盖识别、筛选前移除、题录筛选、全文获取、全文评估、排除理由和最终纳入。
- 项目证据页新增 PRISMA 审计台账、流程可视化、批次新增/编辑/删除和全文获取状态入口。
- 可导出 SVG 流程图、UTF-8 CSV 审计台账和 JSON 原始数据。
- 文献安全合并保留全文获取记录，并在两个显式状态冲突时阻止合并。
