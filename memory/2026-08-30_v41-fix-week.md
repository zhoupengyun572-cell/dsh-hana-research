## 已实现

### 数据丢失级修复

- **删除项目不再误删共享论文的证据链**（`lib/store.js` deleteProject）：论文维度的汇总笔记/阅读进度/逐句笔记/引文只在该论文删除后不再属于任何项目时清理；此前同一篇论文加进项目 B 后删除项目 A 会连带清空 B 中的全部证据链。路径拼接同步改用与 syncProjectNotesFile 一致的 safeProjectId。新增回归测试（共享论文存活/孤儿级联/末项目删除三层断言）。
- **阅读器退出不再丢最新逐句笔记**（`web/src/app.jsx` 保存队列）：entry.patch 语义改为"仅存未送达增量"，发送时快照移出、成功置空 promise、失败把内容放回（保留发送期间新值）；flushSentenceSaves 改为逐条串行冲刷（先等在途落地再补发剩余增量）。旧实现中"成功保存过一次→再编辑→退出"的最新编辑会被静默丢弃。新增 beforeunload 守卫覆盖逐句笔记（此前只覆盖汇总笔记/批注）。
- **结构化证据字段不再互相覆盖**（`web/src/app.jsx` SentenceNoteCard）：setEvidenceField 以上一次本地编辑（evidenceRef）为合并基准；旧实现以未刷新的 props 为基准，防抖窗口内连填两个字段会丢前一个。

### 功能失效修复

- **强制深色主题真正生效**（`web/src/theme.js` + `web/src/app.jsx` + `web/src/main.jsx`）：paletteFromTokens 增加 mode 参数，强制模式与宿主明暗相左时整体改用内置调色板（旧实现 light/dark 两槽共用同一 overlay，强制深色后面板与画布仍是宿主浅色）；EmbedPDF 无运行时换肤 API，主题变化以颜色内容 key 重挂载画布（重挂载时重置批注导入去重 ref，页码/缩放/批注经既有 effect 自动恢复）；auto 模式在无宿主 token 时跟随系统 prefers-color-scheme；首帧着色（main.jsx）尊重持久化偏好。

### API 管线加固（lib/api.js）

- handle() 路由匹配包 try/catch：非法百分号编码（`/papers/%ZZ/…`）显式返回 400，不再悬挂请求。
- 请求体超限 413（UPLOAD_TOO_LARGE）正确透传；读体失败返回 400（旧实现吞掉后 body=null 变 500）。
- 处理器未捕获异常兜底 500（headersSent 时只记日志终止）。
- 质量导出项目不存在改抛 ResearchStoreError，正确映射 404（旧实现误报 500）。

### UI 层修复（assets/research.js）

- 「管理 ▾」菜单外点关闭改为模块级单一 document 监听 + 引用更新；旧实现每次 renderLiterature（14+ 调用点）都叠加一个捕获级监听且永不移除。
- pollTranslationDoc 增加面板脱管退出条件：抽屉关闭/视图切走后停止 1.5s 轮询。
