# v33 双人独立筛选里程碑

日期：2026-08-26

## 本轮目标

在现有系统综述筛选工作台上加入两位审查者的独立判断、盲态展示、冲突仲裁和一致性统计，同时保持旧项目和单人筛选流程兼容。

## 已完成

- 数据库升级到 schema 17，新增双人筛选配置、独立判断和冲突仲裁表。
- 两位审查者分别保存题录/摘要与全文判断；双方完成前不展示对方的具体结论。
- 判断一致时自动形成最终结果；判断不一致时进入冲突队列，仲裁后再写入最终结果。
- 原始一致率和 Cohen's kappa 仅根据两位审查者的原始成对判断计算，仲裁结果不会提高一致性。
- 双人模式提供审查者切换、配对进度、一致率、kappa、待仲裁数量和冲突处理入口。
- 单人模式保持原有批量筛选与逐篇筛选行为；旧判断可在启用双人模式时选择导入为审查者 A。
- 新增配置、独立判断、仲裁 API，并覆盖输入校验和兼容行为。
