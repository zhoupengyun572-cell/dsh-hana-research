# 社区发布 R2：隐私安全与空白启动

时间：2026-08-28（Asia/Shanghai）

## 目标

确保社区用户首次安装不会获得作者研究数据、本机路径或其他开发环境信息，同时保留现有用户数据库。

## 已完成

- `ResearchStore` 默认只初始化数据库结构，不再自动写入示例项目和示例文献。
- 示例数据改为显式 `seedDemoData: true`，仅供测试和开发环境调用。
- 示例项目改为通用名称，不再包含作者的真实研究项目名称。
- 健康接口不再返回数据库绝对路径。
- 公开文档中的作者本机路径与本地包路径已改为 `$DSH_HOME`、`$CODEX_HOME` 等通用表达。
- 发布元数据测试新增隐私扫描，阻止作者用户名、本机包路径和真实项目名称重新进入公开源码或文档。
- 既有用户数据库不会被清空、覆盖或重新播种。

## 验证

- 默认新建数据库的项目和文献列表均为空。
- 显式测试模式仍可生成稳定示例数据，原有功能回归测试不受影响。
- 全部 Node 测试：158/158 通过；Markdown 编辑器测试：7/7 通过。

## 后续边界

- R3 将对实际 npm 发布包再做一次文件级隐私扫描。
- R8 公开时不直接暴露当前内部开发历史，采用清洁的公开发布历史并再次扫描。
