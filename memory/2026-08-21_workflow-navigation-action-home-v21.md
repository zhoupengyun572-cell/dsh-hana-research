# 2026-08-21 工作流导航与行动首页里程碑（v21）

## 目标

- 将插件从“功能集合”收敛为清晰的研究工作流。
- 项目概览优先回答“现在做什么”，减少统计和工具同时争夺注意力。

- 顶栏新增稳定的双入口导航：“找文献 / 做研究”，当前工作区使用 `aria-current` 标识。
- 项目属性从标题区移入“项目设置”渐进披露；上传、证据矩阵、导出与综述收进“更多项目工具”。

- 普通项目笔记与“研究任务”分离，任务不再重复出现在笔记列表。
- 新建任务、完成/重开任务、新建笔记、删除笔记改为 DOM 局部更新，保留当前页签、筛选和滚动位置。
- 新增局部更新计数同步：任务标题、筛选数量、抽屉页签提醒、普通笔记数量。

## 交互原则

- 生产力工具采用 Emil 为主、Jakub 为辅：高频筛选和任务状态即时切换，不增加装饰动画。
- 仅导航悬停与渐进披露使用 140–160ms 的自定义缓动；支持 reduced motion。
- 每个项目概览只保留一个主按钮，其余能力降为状态卡动作或折叠工具。
