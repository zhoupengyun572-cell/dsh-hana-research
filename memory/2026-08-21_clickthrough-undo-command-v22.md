# 2026-08-21 点击穿透、撤销与快捷命令里程碑（v22）

## 真实 Harness 核验

- 用户启动 DeepSeek Harness 后，已在实际桌面窗口确认 v21 被加载。
- “找文献 / 做研究”导航、真实项目卡片、项目概览三层信息均正确显示。
- 发现真实 WebView 环境下项目抽屉可能短暂生成后立即关闭；本地浏览器测试此前未复现。

## 根因与修复

- 宿主合成点击可能在抽屉已经出现后才结束，从而被新出现的遮罩误判为外部点击。
- 抽屉打开时记录时间戳，260ms 内忽略遮罩关闭事件；遮罩监听改为页面级稳定绑定，不再每次打开临时注册。
- 新增专项测试，模拟打开瞬间的遮罩点击，确保抽屉保持可见。

## 新功能

- 普通笔记和文献关系删除后显示 7 秒撤销条。
- 撤销会通过真实 API 重建笔记或关系，而不仅是恢复界面；失败时保留错误反馈。
- 新增 `Ctrl/⌘K` 快捷命令面板，并在顶栏提供低干扰入口。
- 命令支持键盘筛选、上下选择、Enter 执行、Esc 关闭；可搜索当前工作区、切换文献/项目、打开默认项目、新建项目、切换证据/任务和打开设置。

## 动效原则

- 快捷命令属于偶发操作，使用 190ms 进入与 120ms 退出。
- 撤销条使用 180ms 入场、120ms 退场；任务筛选与键盘命令执行本身不添加动画。
- 所有新增动效均提供 `prefers-reduced-motion` 无动画路径。
