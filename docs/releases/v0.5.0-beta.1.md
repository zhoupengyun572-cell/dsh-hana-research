## Hana Research 0.5.0-beta.1

本次预发布面向心理学与社会科学研究工作流，新增 AI 预筛、全库 PDF 全文检索与引用核验，并完成发布依赖和 CI 稳定性加固。

### 主要更新

- **AI 预筛（第三评审）**：依据项目纳排标准生成 include / exclude / uncertain 建议与置信度；不覆盖人工双盲判断，支持暂停、取消和断点续跑。
- **全库全文检索**：本地提取 PDF 文本并写入 SQLite FTS5，支持中英文检索、页码定位、高亮和索引重建。
- **引用核验**：通过 Crossref 与 OpenAlex 生成已确认、字段冲突、未收录、需人工核对四态审计账本。
- **Agent 工具扩展**：新增 `hana_research_get_ai_screening`，工具总数增至 21。
- **可靠性与安全**：Tiptap 升级至 3.31.3，消除已知 XSS/ReDoS 公告；根项目与前端依赖审计均为 0 个已知漏洞；PDF 提取测试改用本地 fixture，避免网络抖动导致 CI 随机失败。

### 兼容性

- 数据库 schema：v19 → v22，升级前自动创建 `.bak-v22-*` 备份。
- Node.js：≥ 22.13.0。
- 已验证：Windows + DeepSeek Harness；CI 覆盖 Ubuntu/Windows × Node 22/24。
- macOS/Linux 实机尚未验证。

- `dsh-hana-research-0.5.0-beta.1.tgz`
